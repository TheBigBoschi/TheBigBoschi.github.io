# TheBigBoschi.github.io
My custom site built using Hugo and Blowfish.

This aims to be a portfolio of my projects, to display them and allow me to keep track of everything I did, and how I did it.

To build the site locally you need the right version of hugo, currently the right version it's in the root folder of the project. To check the required version of Hugo go to themes/blowfish/release-version/hugo-latest.txt, there the required Hugo version is specified.

To make your life easier download blowfish-tools, it's a package to manage the site easily before building it.

After major updates modify the HUGO_VERSION line inside the .github/workflows/hugo.yaml to specify which Hugo version use to compile the site.
